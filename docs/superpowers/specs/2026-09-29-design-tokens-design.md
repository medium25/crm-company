# Единый дизайн-код (токены) — дизайн

Дата: 2026-09-29. Статус: черновик на ревью.

## Цель

Один источник правды для внешнего вида: размеры текста, радиусы, высоты контролов, цвета, карточки. Страницы и компоненты берут только токены. Сейчас разнобой: 13 произвольных `text-[Npx]` в 97 файлах, hex-цвета в 17 файлах, `rounded-xl/lg/2xl/md` в 9 файлах, контролы высотой 32/36/40/44/48px.

Общий вид приложения (светлая тема, navy-акцент, Nunito Sans, тёмная тема только на «Заявках») сохраняется. Меняются значения токенов на набор «C» (мягче и крупнее) и убираются все обходы токенов.

## Решения, принятые с пользователем

- Цель: свести всё к токенам (не менять стиль целиком, не писать только гайд).
- Что унифицируем: размеры текста, карточки и блоки, кнопки/поля/фильтры, цвета.
- Набор значений: вариант C.
- Плотность: карточки, кнопки, поля, модалки по C. Таблицы и канбан «Заявки» остаются компактными, у них от C только радиусы и цвета.
- Выкатка поэтапно, каждый этап отдельным деплоем.

## Токены

### Размеры текста (`theme.extend.fontSize` в `tailwind.config.js`)

| Класс | px / line-height | Где |
|---|---|---|
| `text-caption` | 12 / 16 | подписи, бейджи, мелкие пометки |
| `text-small` | 13 / 18 | ячейки таблиц, канбан, подписи полей |
| `text-body` | 14 / 20 | основной текст в карточках, подписи плиток |
| `text-control` | 15 / 20 | текст в кнопках, полях, селектах |
| `text-title` | 17 / 24 | заголовки блоков и модалок |
| `text-page` | 22 / 28 | заголовок страницы |
| `text-kpi` | 36 / 42 | большие числа плиток |

Сведение старых значений: `9/10/11/12px` в `caption`, `13px` в `small`, `14px` в `body`, `15px` в `control` (для заголовков блоков, которые сейчас 15px, `title`), `17px` в `title`, `20/22px` в `page`, `28/32/34px` в `kpi`. Заголовки блоков решаются по месту: если элемент заголовок, то `title`, если текст контрола, то `control`.

### Радиусы (`borderRadius`)

| Токен | Значение | Где |
|---|---|---|
| `rounded-card` | 16px | карточки, панели, модалки |
| `rounded-row` | 12px | вложенные плитки, строки-карточки, канбан-карточки |
| `rounded-field` | 12px | кнопки, поля, селекты |
| `rounded-badge` | 9999px | бейджи, чипы |

`rounded-full` остаётся для кругов (аватары, иконки-кнопки). `rounded-xl/lg/2xl/md` и голый `rounded` заменяются токенами.

### Высоты контролов

- `md`: 48px (`h-12`), текст `control`. Формы, модалки, основные кнопки.
- `sm`: 36px (`h-9`), текст `small`. Фильтры, таблицы, канбан, тулбары.
- `h-10/h-11` в контролах уходят, `h-8` тоже, кроме иконок-кнопок внутри строк таблиц: у них единый размер 32px (`h-8 w-8`), других размеров иконок-кнопок нет.

### Карточки и блоки

- `Card`: фон `surface` (белый), рамка `border` (светлая, вместо `border-strong`), радиус `card`, тень `hover`-уровня по умолчанию (`0 4px 12px rgba(16,24,40,.08)`), отступ `p-6`.
- `Tile` (новый примитив): вложенная плитка, фон `bg`, без рамки, радиус `row`, отступ `p-4`.
- `StatCard`: `Tile` с иконкой, подпись `body`, число `kpi`.

### Цвета

Хардкод hex запрещён. В `index.css` (`:root` и `.dark`) добавляются токены, в `tailwind.config.js` та же обёртка `rgb(var(--…) / <alpha-value>)`:
- `warning`, `warning-bg` (сейчас `#E9B949` в `Button`);
- `info`, `info-bg`;
- `chip` (серый фон бейджей типа/группы, сейчас `#EEF0F3` в `Badge`);
- `chart-1` … `chart-7` (палитра графиков и полос, сейчас `BAR_COLORS` и hex в `charts/`).

Тёмная тема на «Заявках» получает значения тех же токенов в `.dark`, компоненты про тему не знают.

## Компоненты

Общий проп `size: 'md' | 'sm'` (по умолчанию `md`) у `Button`, `Input`, `Select`, `MoneyInput`, `DatePicker`. Страницы не задают высоту, радиус и размер шрифта контролов классами. Вариант `lg` у `Button` убирается, использования переводятся на `md`.

`Badge`: убрать hex (`chip`), форма пилюля для всех вариантов, размер `caption`. Вариант `status-debt` перестаёт быть исключением.

Новые примитивы, только там, где сейчас разметка дублируется на разных страницах:
- `Tile` (см. выше);
- `SectionTitle`: заголовок блока `title` с приглушённой подписью `caption`/`body` рядом (сейчас повторяется вручную на дашборде и платежах);
- `FilterChip`: кнопка-чип фильтра размера `sm`.

Список новых примитивов не расширяется без необходимости на этапе плана.

## Правила и защита от расползания

- `DESIGN.md` в корне репозитория: таблица токенов, «что использовать вместо чего», правило плотности (таблицы и канбан `sm`, остальное `md`).
- `scripts/check-design.mjs`: обходит `src`, падает с перечнем файлов и строк при находке `text-[<число>px]`, `#hex` вне `index.css`, `rounded-xl|lg|2xl|md` и голого `rounded`. Исключения через комментарий `design-ok: причина` в той же строке.
- `package.json`: скрипт `check:design`; `deploy` запускает его перед `build`.
- На этапах 1–4 проверка работает в режиме предупреждения по ещё не переведённым разделам (список путей-исключений в самом скрипте, сужается по мере этапов). На этапе 5 список исключений пуст.

## Этапы выкатки (каждый отдельный деплой)

1. Токены, базовые компоненты (`Button`, `Card`, `Input`, `Select`, `Badge`, `StatCard`, `Modal`, `Tabs`, `Tile`, `SectionTitle`, `FilterChip`), `DESIGN.md`, скрипт проверки. Изменения видны сразу везде, где страницы используют компоненты.
2. Дашборд и Платежи (включая `charts/`, `PaymentSourceAnalysis`).
3. Студенты, Группы, Посещаемость, Учителя.
4. Заявки, Задачи, Пробные, Покинувшие (канбан, тёмная тема, планшет Laylo).
5. Настройки, модалки, остатки. Список исключений скрипта пустеет, проверка обязательна.

## Проверка

- После каждого этапа: `npm run check:design`, `npm run lint`, `npm run build`.
- Визуально через dev-сервер: главная страница этапа, модалка, таблица, планшетная ширина (768px). На этапе 4 дополнительно тёмная тема «Заявок».
- Регрессия: высоты и переносы в таблицах и канбане (у канбана карточки не должны вырасти), кликабельные зоны на планшете не меньше 36px.

## Риски

- `md` 48px вместо 44px увеличивает формы и модалки. Модалки с длинными формами могут потребовать прокрутки, проверяем на этапах 3–5.
- Сведение `13/14/15px` в шкалу меняет размеры на 1px в местах, где сейчас «между» значениями. Принято осознанно ради единой шкалы.
- Тёмная тема: новые токены обязаны иметь значения в `.dark`, иначе «Заявки» получат светлые пятна.

## Вне охвата

- Смена шрифта и общей палитры.
- Тёмная тема на страницах кроме «Заявок».
- Смена сетки, навигации, структуры страниц.
- Компоненты и логика, не связанные с внешним видом.
