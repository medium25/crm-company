# Должники: чётные/нечётные → учитель → список

## Проблема

Раздел "Должники" в Студентах — плоский список всех, у кого баланс < 0.
Неудобно для реальной работы: администратор обзванивает должников по
учителям и по дням занятий (чтобы напомнить прямо перед уроком). Нет места
поставить себе напоминание "перезвонить завтра" или быстро глянуть историю
переписки по конкретному студенту, не уходя со страницы.

## Что меняется

Заменяет текущий раздел `debtors` в `StudentsPage.jsx` (флажок в дашборде
`/students?debtors=1` — отдельная штука, плоский фильтр в "Все ученики", не
трогаем).

### Навигация (3 уровня, drill-down как в "Посещаемость")

1. **Чётные / Нечётные дни** — 2 карточки со счётчиком должников в каждой
   (по `group.schedule.type`, только `even`/`odd` — `weekdays` в реальных
   данных не встречается, обработку не делаем).
2. **Учителя** этой чётности — карточки со счётчиком должников на учителя
   (учитель попадает в список, если хоть у одной его группы этой чётности
   есть активный студент с `balance < 0`).
3. **Список должников** этого учителя — таблица: Имя, Телефон, Баланс,
   Группа, + 3 иконки действий (Флаг / Комментарий / Задача).

Должник = `student.status === 'active' && !isArchived && balance < 0`
(то же определение, что и сейчас). Если у студента активные записи у
нескольких учителей/чётностей — он появляется в каждой соответствующей
ветке отдельно.

### Флаг

Ничего нового — переиспользуем существующее `student.isFlagged` и
`toggleFlag` (уже есть на карточке студента). Клик по иконке в списке
переключает.

### Комментарий

Клик открывает модалку с существующим `CommentsTab` (entityType: 'student')
— тот же тред, что на карточке студента, не урезанная версия. Значок
подсвечивается, если у студента есть хоть один комментарий.

### Задача с напоминанием (новое)

Новая коллекция `tasks`:

```
tasks/{id}
  studentId, studentName   — денорм., для быстрого списка на студента
  branchId
  text                     — что сделать
  dueDate                  — Timestamp, дата напоминания
  status                   — 'pending' | 'done'
  createdBy, createdByName, createdAt
  doneBy, doneAt           — null пока не выполнена
```

Список задач с историей (не одна активная — прошлые остаются, можно
отметить выполненной). Клик по значку открывает модалку: список задач
студента (просроченные pending — красным, выполненные — зачёркнуты/серым)
+ форма добавить новую (текст + дата).

Напоминание — **только визуальное**: значок в таблице должников красный/
подсвечен, если есть просроченная невыполненная задача. Push/SMS не
делаем — отдельная большая тема, не в этой итерации.

### Firestore rules

```
match /tasks/{id} {
  allow read, write: if isAdmin();
}
```
(Учителя к должникам не имеют отношения по ролям — уже так во всей системе.)

## Не входит в эту итерацию

- Push/SMS-напоминания по задачам
- Массовые действия (отметить всех выполненными и т.п.)
- Изменение фильтра `/students?debtors=1` (дашборд) — остаётся как есть
- Категория "по дням недели" — нет данных, нет смысла
